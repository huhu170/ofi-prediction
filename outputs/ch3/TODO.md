### 图 3.4-1：PV-CrossAttention架构示意图 ✅ 已完成

**输出路径**：`figures/fig_3.4-1_pv_crossattn.png`

**图形布局**：自上而下的数据流图，三路并行 + 融合

**内容描述**：
1. **输入层**（顶部，两个并行输入框）：
   - 左框：价格特征序列 **P** ∈ ℝ^(T×d_p)
     - 包含：收益率r, ΔOHLC, RSI, MACD 等
   - 右框：成交量特征序列 **V** ∈ ℝ^(T×d_v)
     - 包含：成交量V, 相对成交量RV, 成交不平衡TI, 量价相关性ρ_PV 等

2. **三路注意力分支**（中间层，三个并行模块）：
   - **左分支 - 自注意力**：
     - 标准 Multi-Head Self-Attention
     - 输出 H_self
   - **中分支 - P→V 交叉注意力**：
     - Query = P·W_Q^P, Key = V·W_K^V, Value = V·W_V^V
     - 学习"价格模式下哪些成交量信号相关"
     - 输出 CrossAttn_{P→V}
   - **右分支 - V→P 交叉注意力**：
     - Query = V·W_Q^V, Key = P·W_K^P, Value = P·W_V^P
     - 学习"成交量模式下哪些价格信号相关"
     - 输出 CrossAttn_{V→P}

3. **融合层**（底部）：
   - 残差连接：H_self + CrossAttn_{P→V} + CrossAttn_{V→P}
   - LayerNorm 归一化
   - 输出：**H_PV** ∈ ℝ^(T×d_model)

**数据流箭头**：实线箭头表示数据流，虚线框表示可选的注意力权重可视化输出

**参考论文位置**：第三章第四节"一、量价交叉注意力机制"，公式(3.4-1)至(3.4-7)

### 图 3.4-2：可学习尺度融合模块（LSF）架构示意图 ✅ 已完成

**输出路径**：`figures/fig_3.4-2_lsf_module.png`

**图形布局**：左侧四路并行编码 + 中间门控网络 + 右侧融合输出

**内容描述**：
1. **输入层**（左侧，四个并行输入框）：
   - **X_1min**：1分钟K线序列 (60, 22)
   - **X_5min**：5分钟K线序列 (24, 22)
   - **X_60min**：60分钟K线序列 (12, 22)
   - **X_daily**：日K线序列 (20, 22)
   - 每个框标注维度：(时间步, 特征维度)

2. **尺度编码器**（四个并行 Transformer 块）：
   - 每个尺度独立的 Transformer Encoder
   - 包含：PV-CrossAttention + Self-Attention + FFN
   - 输出：H_1, H_2, H_3, H_4 ∈ ℝ^(d_model)
   - d_model = 256

3. **市场状态编码器**（单独分支，虚线框）：
   - 输入：波动率 σ_20 + 趋势强度 ADX_14 + 相对成交量 RV
   - MLP 编码 → 状态向量 **s_t** ∈ ℝ^(d_s)

4. **门控网络**（中间核心模块，高亮显示）：
   - 输入：拼接 [s_t; H_1; H_2; H_3; H_4]
   - 计算：**g** = softmax(W_g · input + b_g)
   - 输出：四个权重 [α_1, α_2, α_3, α_4]，Σα_i = 1
   - 用饼图/条形图示意权重分配

5. **加权融合**（右侧输出框）：
   - 计算：**H_fused** = Σ α_i · H_i
   - 输出维度：(d_model,) = (256,)

**可解释性标注**：用虚线引出"门控权重α_i可用于分析模型关注偏好"

**参考论文位置**：第三章第四节"二、可学习尺度融合模块"，公式(3.4-8)至(3.4-11)

**图形布局**：自上而下的完整数据流图，展示端到端架构

**内容描述**：
1. **输入层**（顶部，四个并行数据源）：
   | 尺度 | 输入维度 | 说明 |
   |------|----------|------|
   | 1min | (60, 5) | 60根K线 × OHLCV |
   | 5min | (24, 5) | 24根K线 × OHLCV |
   | 60min | (12, 5) | 12根K线 × OHLCV |
   | Daily | (20, 5) | 20根K线 × OHLCV |

2. **特征工程层**（第二层）：
   - OHLCV → 22维特征（量价/技术/波动）
   - 输出：(T, 22) for each scale

3. **嵌入层**（第三层，用虚线框）：
   - 线性投影：X·W_E + b_E → (T, d_model)
   - 可学习位置编码：PE ∈ ℝ^(T×d_model)
   - 时间戳编码：TE = Embed_hour + Embed_weekday
   - 输出：Z_0 = E + PE + TE

4. **PV-CrossAttention 层**（第四层，**创新点1**）：
   - 引用图 3.4-1 的架构
   - 输出：各尺度的量价交互表征 H_PV^(i)

5. **LSF 融合层**（第五层，**创新点2**）：
   - 引用图 3.4-2 的架构
   - 输出：融合表征 H_fused ∈ ℝ^(256)

6. **Transformer 编码器**（第六层）：
   - N=4 层堆叠
   - 每层：Multi-Head Self-Attention + FFN + LayerNorm
   - 输出：最终表征 H_final ∈ ℝ^(256)

7. **输出层**（底部，两个并行输出头）：
   - **分类头**：Linear(256, 3) → Softmax → P(上涨/下跌/平稳)
   - **回归头**：Linear(256, 1) → 预测收益率 r̂
