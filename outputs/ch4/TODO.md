## 四、执行顺序建议

### 前置步骤：数据准备（Batch 0）

> ⚠️ 运行实验前必须先完成数据准备

```bash
# Step 1: 数据清洗（从数据库读取原始K线）
python scripts/10b_kline_data_cleaner.py --all --multi-scale

# Step 2: 特征计算（22维特征 + 标签）
python scripts/11b_kline_feature_calculator.py --all --multi-scale

# Step 3: 数据集构建（滑动窗口 + 标准化）
python scripts/12b_kline_dataset_builder.py --all --multi-scale
```

**数据配置（与论文第三章对齐）**：
- 输入特征：22维（见表3.3-1）
- 输入窗口：1M=60步, 5M=24步, 60M=12步, 日K=20步
- 标签阈值：α=0.002（三分类）
- Gap：30分钟（防止标签泄漏）
- 标签编码：{-1,0,+1} → {0,1,2}（PyTorch兼容）
