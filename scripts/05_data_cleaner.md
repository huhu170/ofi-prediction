# K线数据清洗模块说明

## 概述

`10b_kline_data_cleaner.py` 实现了论文第三章第一节中的数据预处理流程，将原始K线数据清洗为可用于特征计算的标准格式。

## 清洗规则

| 清洗项 | 规则 | 论文依据 |
|--------|------|----------|
| **交易时段** | 排除开盘/收盘5分钟 (09:35-12:00, 13:00-15:55) | 避免集合竞价异常 |
| **价格异常** | 单根K线涨跌幅 > 10% 标记为NaN | 过滤极端事件 |
| **成交量异常** | Z-score > 10 用前值填充 | 防止异常放量影响 |
| **缺失处理** | 价格前向填充，成交量填0 | 保证数据连续性 |
| **连续性校验** | 检测时间跳跃（缺失K线） | 数据完整性检查 |

## 配置参数

```python
CLEAN_CONFIG = {
    'max_price_change_pct': 10.0,   # 单根K线最大涨跌幅（%）
    'min_volume': 0,                 # 最小成交量
    'max_volume_zscore': 10.0,       # 成交量Z-score异常阈值
    'max_gap_minutes': 5,            # 分钟K线最大允许缺失
}
```

## 港股交易时段

```python
HK_TRADING_SESSIONS = {
    '1M': [
        (09:35, 12:00),  # 上午（排除开盘5分钟）
        (13:00, 15:55),  # 下午（排除收盘5分钟）
    ],
    # 5M, 60M 类似
    'DAY': None,  # 日K无需时段过滤
}
```

## 使用方法

```bash
# 清洗单只股票的1分钟K线
python 10b_kline_data_cleaner.py --code HK.00700 --ktype 1M

# 清洗所有时间尺度
python 10b_kline_data_cleaner.py --code HK.00700 --multi-scale

# 清洗所有股票
python 10b_kline_data_cleaner.py --all --multi-scale

# 指定日期范围
python 10b_kline_data_cleaner.py --code HK.00700 --start 2023-01-01 --end 2024-12-31
```

## 输出格式

清洗后的数据保存为Parquet文件：

```
data/processed/
└── HK_00700/
    ├── kline_cleaned_1M.parquet
    ├── kline_cleaned_5M.parquet
    ├── kline_cleaned_60M.parquet
    └── kline_cleaned_DAY.parquet
```

输出列：
- `ts`: 时间戳
- `code`: 股票代码
- `open`, `high`, `low`, `close`: OHLC价格
- `volume`: 成交量
- `turnover`: 成交额
